# 💧 HydroPurify OS (Titan #22)
### Industrial Neo-Brutalism Municipal Water Treatment Plant SCADA & PDAM Billing Counter

## Overview
HydroPurify OS adalah sistem automasi kendali industri dan loket rekening pelanggan PDAM Tirta Kencana yang dirancang khusus dengan filosofi desain **Industrial Neo-Brutalism**.

## 4 Rute Produksi
1. **SCADA Command Deck (`/`)**
2. **PDAM Tariff & Metering Counter (`/billing/`)**
3. **Water Quality Lab Assay Studio (`/lab/`)**
4. **Official Stamped A4 Certificate (`/surat/`)**

## Tech Stack
Next.js 16, TypeScript, Tailwind CSS v4, Lucide React.
